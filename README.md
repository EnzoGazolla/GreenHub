## GreenHub
**Plataforma de Gestão Sustentável Integrada para condomínios residenciais.**

##  Sobre o Projeto

O projeto consiste em uma plataforma de Gestão Sustentável Integrada para condomínios residenciais, disponível via web ou aplicativo. O objetivo principal é conectar moradores e a administração do condomínio com foco total em sustentabilidade e eficiência.

### Funcionalidades Principais:
- **Monitoramento via IoT:** Dashboard de consumo em tempo real para água, gás e energia.
- **Gamificação Sustentável:** Ações como o descarte correto de resíduos e a geração de energia solar geram pontos. Esses pontos podem ser convertidos em descontos na taxa condominial para engajar a comunidade.
- **Gestão de Resíduos:** Plataforma centraliza o agendamento de coleta de lixo e recicláveis.
- **Mobilidade Urbana:** Sistema integrado de caronas solidárias e controle inteligente de vagas para veículos elétricos.
